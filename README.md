Slide tương tác và tài liệu tự học cho học phần CSC10007.

- [Học trên GitHub Pages](https://pnthuc.github.io/os-gk/)

Trong `output/slidev`, chạy `npm ci` rồi `npm run dev` (Node.js 24) để xem tại máy. Sau khi sửa nội dung, đẩy lên nhánh `main` để GitHub Actions dựng và cập nhật trang.

Giáo trình, đề chụp và các tài liệu tham khảo của bên thứ ba chỉ nằm trong thư mục học tập tại máy.
